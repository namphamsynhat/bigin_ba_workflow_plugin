# Bigin BA vault

This folder is the team's second brain for one client project. The `bigin-ba` plugin maintains it.

- Settings: `bigin.md`. Current state and what is waiting: `INDEX.md` (generated).
- To move work forward, run `/bigin-ba:next`. To look something up, run `/bigin-ba:ask`.
- Never edit `## Raw` in `00-inbox/`. New information always enters through `/bigin-ba:intake`.
- Only a person approves. Never set `status: approved` by hand or run `bigin approve` unasked.
