# Glossary

One row per business term, in this project's own meaning. **This file is yours to edit at any time** — add a row, fix a meaning, add another name. Agents read it before they write, and use the **Term** in every use case, rule and story.

- **Term** — the one name we write.
- **Meaning** — one or two plain sentences. Blank means nobody has stated it yet: fill it in, or ask the client. It is never guessed.
- **Also called** — other names for the same thing, separated by `;` — the client's wording, a Vietnamese term, a code or Jira name.
- **Source** — where the term came from (`INT-### #row`), or your name for a row you added.

To rename a term: change **Term** and move the old name into **Also called**. `bigin lint --full` then lists every use case and rule that still uses the old name.
