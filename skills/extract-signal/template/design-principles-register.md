# Design Principles

Durable, cross-cutting design/brand/tone/accessibility/interaction/content preferences — the kind of constraint that outlives any one feature. `extract-signal` appends a row here when a signal reads as this durable, **in addition to** filing it normally on its anchored feature's Signal Log — never instead of that filing.
